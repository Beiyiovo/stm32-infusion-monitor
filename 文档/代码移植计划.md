## 三、搬运时必改的 3 个地方（项目1 的踩坑）

1. **宏定义里的引脚**（`bsp_*.h` 或 `main.c` 顶部）—— PB6/PB7/PA0/PB0/PB1/PA2/PA3/PA9/PA10 不变，
   但项目1 里若把 MPU6050/MAX30102 的引脚也写进去了，要删掉。
2. **`-O2` 与 Flash 上限**：项目1 最终 27400 字节 / 32768。项目2 去掉两个大模块后约 20~22KB，
   但如果把整张 HTML 页面写进常量，注意别超。
3. **烧录**：这块蓝板没有板载 CH340，只能 USB-TTL 串口 ISP，且**实测 9600 才稳**。
   参考 `T:\AS\bishe501\flash_any.bat` 的握手探测逻辑，改成扫本工程目录。

## 四、`08` 这一层怎么做到"两种方案都能换"

**把"数据上报"做成一个函数（弱符号/函数指针）**，两套实现各自一个 .c 文件：

```
   report.h        →  void report_publish(float t, float w, uint8_t state);
   report_http.c   →  AP 模式：CIPMUX/CIPSERVER，收到 +IPD 就回一张固定 HTML
   report_mqtt.c   →  STA 模式：AT+CWJAP 连路由 + AT+MQTTCONN + AT+MQTTPUB
```

`main.c` 只调 `report_publish()`。**导师定哪一种，就编译哪一个 .c，另一个不加入工程。**
