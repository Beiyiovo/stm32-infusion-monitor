# 固件说明

| 文件 | 说明 | 什么时候烧 |
|---|---|---|
| 01_串口心跳 | 串口打印 + 板载 LED 心跳 | 第一次通电验证 |
| 02_OLED显示 | I2C + 中文显示 | 验证屏幕 |
| 03_温度采集 | DS18B20 | 验证温度探头 |
| 04_四键测试 | 四个按键逐个打印 | 判断按键硬件好坏 |
| 05_两级告警 | 黄/红 + 蜂鸣器，7 种工况 | 验证声光 |
| 06_称重 | HX711 原始值 + 克数 | 验证称重模块 |
| 07_红外数滴 | 外部中断计数 + 滴速 | 验证数滴 |
| 08_WiFi上报 | ESP32 AT 序列 + TCP | 验证网络 |
| 09_整机v1(历史) | 早期英文界面版本 | 仅作对照，**不建议烧** |
| 10_接线自检 | 一次上电验全部接线 | ★ 拿到板子先烧这个 |
| 11_称重标定 | 定零点 + 算换算系数 | ★ 换传感器/改结构后必烧 |
| 12_LED测试 | 红黄各亮 2 秒 | 判断 LED 好坏 |
| 13_整机v2(当前) | 中文界面 + 四键 + 分级告警 + 上报 | ★ 最终固件 |

.py/.hex 说明：`.bin` 用串口 ISP 或 ST-Link 烧；`.hex` 用 ST-Link / STM32CubeProgrammer 烧。

**烧录线序（串口 ISP）**：USB-TTL TXD→PA10，RXD→PA9，GND→GND；BOOT0=1 → 复位 → 烧 → BOOT0=0 → 复位。
