# 测试记录

> 这个文件夹放"能证明东西真的达标"的证据。**没有记录 = 没做过。**

## 这里放什么

| 子目录 / 文件 | 内容 | 命名建议 |
|---|---|---|
| `照片/` | 面包板接线、整机外观、屏显内容 | `2026-10-25_面包板全貌.jpg` |
| `串口日志/` | 串口助手保存的 .txt（开机信息、报警触发、联网过程） | `2026-10-26_称重标定.log.txt` |
| `标定/` | 称重与温度的原始数据、拟合结果 | `2026-10-27_称重标定.xlsx` |
| `问题记录.md` | 每次翻车：现象 → 排查 → 根因 → 解决 | 持续追加 |

## 每次测试必须记全这 6 项

| 日期 | 测什么 | 条件（电压/环境/负载） | 数据 | 结论 | 备注 |
|---|---|---|---|---|---|
| | | | | | |

**结论只有三种写法**：已达成 / 部分达成 / 未达成。
禁止"基本满足""总体良好"——这类词在答辩时一定会被追问"到底满没满足"。

## 关键判据（摘自《502可行性验证方案》）

| 项目 | 判据 |
|---|---|
| 称重满量程误差（100/200/500/800g） | ≤ ±2g |
| 称重回零误差 / 重复性 / 迟滞 | 各 ≤ 2g |
| 温度（室温 / 37℃ / 42℃ 三点） | 与体温计差 ≤ 0.5℃ |
| 报警分级 | 黄灯预警、红灯+蜂鸣报警各触发一次 |
| 网页 | 手机 3 秒内打开，数据与 OLED 一致 |
| 连续运行 | 2 小时不死机、零点漂移 ≤ 2g |

## 记录纪律

1. **边测边记**，不靠回忆补
2. 数据带单位、带量程、带次数（"3 次，极差 1.2g"而不是"很稳"）
3. 测失败的也留着——那是最有说服力的排查过程
